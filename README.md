# SQL学习笔记

## 概述

本仓库包含了系统化的SQL学习笔记，使用Jupyter Notebook记录，主要基于MySQL数据库。笔记涵盖了SQL的基本概念、语法和各种操作技巧，从基础连接到复杂查询都有详细说明。

## 目录内容

### 1. MySQL连接 (01.MySQL连接.ipynb)
- Jupyter魔法方法连接MySQL
- 使用Python库连接MySQL

### 2. SQL通用语法及分类 (05.基础-SQL-通用语法及分类.ipynb)
- SQL分类介绍：
  - DDL (数据定义语言)
  - DML (数据操作语言)
  - DQL (数据查询语言)
  - DCL (数据控制语言)

### 3. DDL - 数据定义语言 (06-10.基础-SQL-DDL.ipynb)
- 数据库操作：创建、查询、修改、删除
- 表操作：创建表、删除表、修改表结构
- 字段操作：添加、修改、删除字段

### 4. DML - 数据操作语言 (11-14.基础-SQL-DML.ipynb)
- 添加数据
- 修改数据
- 删除数据

### 5. DQL - 数据查询语言 (15-23.基础-SQL-DQL.ipynb)
- 基本查询
- 条件查询 (WHERE)
- 聚合函数 (count、max、min、avg、sum)
- 分组查询 (GROUP BY)
- 排序查询 (ORDER BY)
- 分页查询 (LIMIT)
- 执行顺序

### 6. DCL - 数据控制语言 (24-26.基础-SQL-DCL.ipynb)
- 用户管理：创建、修改、删除用户
- 权限控制：授予权限、撤销权限
- 查询权限

### 7. 函数 (27-31.基础-函数.ipynb)
- 字符串函数
- 数字函数
- 日期函数
- 流程控制函数
- 窗口函数

### 8. 约束 (32-36.基础-约束.ipynb)
- 主键约束
- 非空约束
- 唯一约束
- 默认约束
- 检查约束
- 外键约束

### 9. 多表查询 (37-50.基础-多表查询.ipynb)
- 多表关系：一对多、多对多、一对一
- 连接查询：
  - 内连接
  - 外连接（左连接、右连接）
  - 自连接
- 子查询：
  - 标量子查询
  - 列子查询
  - 行子查询
  - 表子查询

### 10. 事务 (51-56.基础-事务.ipynb)
- 事务的基本概念
- 事务的ACID特性
- 事务控制

## 环境配置

这些笔记使用了以下环境：
- Python 3.11.9
- Jupyter Notebook
- MySQL 数据库
- mysql-connector-python
- ipython-sql 扩展

## 示例数据

笔记中使用了MySQL自带的`world`数据库进行演示，这个数据库包含了国家、城市和语言等相关数据。

## 使用方法

1. 确保安装了Python和Jupyter Notebook
2. 安装必要的Python库：`mysql-connector-python`、`ipython-sql`
3. 配置本地MySQL服务器
4. 打开Jupyter Notebook，浏览和运行笔记中的代码

## 学习建议

建议按照目录顺序学习，从基础概念开始，逐步深入到复杂查询和高级功能。每个笔记本中都有详细的示例和解释，可以直接在Jupyter环境中运行代码查看结果。
